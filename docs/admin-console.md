# 管理后台与用户用量

后台继续使用现有 Worker/D1 账号体系，不额外部署第三方管理平台。个人账号入口为 https://accounts.hilex.me/ ，管理控制台独立位于 https://accounts.hilex.me/admin 。管理员与普通用户登录后默认进入个人账号页，管理员可点击“进入管理控制台”，控制台提供“返回我的账号”。管理功能包含账号与额度、模型管理、API Key、费用与预算、告警中心和通告发布，个人功能包含用量、通知、邮箱绑定和密码设置。未登录打开控制台会跳转到登录页，登录后返回控制台；普通用户或尚未修改初始密码的管理员不能访问管理页面。页面 HTML 与所有管理接口均校验权限，不依赖前端隐藏按钮。管理 API 路径和客户端认证方式保持不变，不需要新域名或额外隧道。

只有已修改初始密码的管理员能访问管理 API。普通用户仅能查看自身额度与记录。

## 日常操作

- 用量总览展示全局账号数、启用数、所选日请求数、失败/进行中、OpenAI 识别分钟和合成字符。
- 账号列表支持显示名、邮箱、IP 搜索，按启用/封禁状态筛选，按北京时间日期查看，每页最多 50 条。
- 列表对比各账号请求次数、所选月份 Luna tokens、所选日识别和合成用量，以及最近 IP / 活动时间。
- 点击显示名进入 `/admin/users/{id}`。在该页查看账号状态、最近活动与用量，并展开「权限、额度与模型」配置单个账号。返回列表时保留筛选和页码。
- “统一默认额度”只影响后续自助注册和管理员创建的账号。改变已有账号时，先勾选账号，再“应用默认额度”；确认框列出账号和本次额度。每次最多 100 个账号，不会同步覆盖其权限或封禁状态。
- “封禁”立即阻止新请求并撤销登录会话，保留历史记录和 Key；解封后用户需重新登录，有效 Key 可继续使用。已发往上游的请求可能继续完成。最后一个有效管理员受数据库 trigger 保护；批量操作若触发保护，整批回滚。
- 用户详情页展示最近登录 IP、最近访问 IP、所选日最近 100 次请求、语音余额、客户端版本、设备 ID、User-Agent 和追踪 ID。密钥单独进入现有 Key 管理，密码重置会撤销全部登录和 Key。

历史日期的用量与**当前**限额对比；系统不重建历史套餐。预留/待核对量也计入已使用，不能当成可用余额。未知 IP 和未接入前缺失的元数据不做推断补齐。

账号列表、用量总览可独立更新。用户详情优先加载账号设置和额度，展开活动记录时才读取访问 IP 与请求。打开全局配置或运行告警只读取对应数据；保存预算不会覆盖注册保护表单的输入。同一天内翻页和筛选可复用 30 秒内的总览，点击「刷新数据」会重新读取总览。默认额度在打开创建或默认额度表单、或批量应用默认额度时读取。列表更新失败时可在原位置重试，旧结果会保留并暂停操作。

## 模型授权与新账号默认值

在「模型管理」维护新账号默认模型。创建或注册时将该列表保存到账号，之后修改默认值只作用于未来账号。GPT-6 Luna 初始在默认列表内，其余模型由管理员选配。迁移时原有白名单保留，原来继承默认的账号固化为迁移时的默认列表。

单个账号的模型权限在用户详情页直接勾选，账号登录和其名下 API Key 使用同一规则。未授权的模型不显示在目录，直接请求返回 `403 model_not_allowed`。服务权限、账号额度、全站预算和云模型暂停仍会生效。自建模型还需要后端启动。

`PATCH /admin/users/{id}` 的 `allowed_model_ids` 接受模型 ID 数组，空数组禁止所有模型，省略保留当前权限。

### 批量模型授权

在用户列表勾选账号，打开「批量模型授权」，选择添加或移除以及模型，确认名单后提交。操作原子执行，保留每个账号未选中的模型。API 使用 `POST /admin/users/bulk`，`patch` 仅提供 `add_model_ids` 或 `remove_model_ids` 中的一项。

### 搜索用量与核对

个人用量和管理员账号详情返回 `web_search` 对象，包含 `day`、`timezone`、`limit`、`used`、`reserved`、`remaining`、`resets_at`。网页搜索日额拒绝返回 HTTP 429，`error.code=web_search_daily_limit`，并在 `X-Helix-Resets-At` 头提供 ISO 8601 重置时间。已用是已结算次数，剩余额度同时扣除预留次数。

核对涉及搜索的请求时，必须同时提交 `web_search_calls`、`expected_web_search_calls`、实际和原金额及 token 用量。搜索次数、token、金额与审计记录在同一事务内更新。确认未调用时将实际搜索次数填 0，可释放当日预留。

## IP 与客户端信息的来源

账号登录 IP 来自 Cloudflare Worker 收到的 `CF-Connecting-IP`。API 请求 IP 只信任回环隧道入口的 Cloudflare 连接头；其他连接使用实际对端地址，不信任任意客户端的 X-Forwarded-For。网关只绑定回环地址，不应把源站端口直接暴露到公网。代理或 VPN 会影响 IP 的地理或设备含义，不能把 IP 当成用户真实身份。

新增登录保存 `last_login_ip` / `last_login_at`，推理请求保存 `client_ip`、`user_agent`、`client_version`、`device_id`。历史请求不会自动补出这些字段。客户端版本和设备 ID 属于不可信诊断信息，不能影响权限或计费。管理员应按业务需要访问这些资料，导出和截图放入私有目录。

## 管理 API

| 接口 | 用途 |
|---|---|
| `GET /admin/overview?q=&status=all&day=YYYY-MM-DD&page=1&page_size=50` | 全局统计和分页账号用量 |
| `GET/PATCH /admin/quota-defaults` | 所有新账号的统一默认额度 |
| `POST /admin/users/bulk` | `{ids: [...], patch: {...}}`，批量额度或 enabled 状态 |
| `GET /admin/users/{id}/details?day=YYYY-MM-DD` | 账号详情、请求、IP 和余额 |
| `PATCH /admin/users/{id}` | 单账号权限和额度 |
| `GET /admin/openai-costs?period=month` | OpenAI 组织每日费用，支持 `month`、`7d`、`30d` |
| `GET /admin/audit` | 最近管理事件 |

统一额度字段为 `rpm`、`daily_requests`、`concurrency`、`luna_monthly_tokens`、`openai_asr_daily_seconds`、`openai_tts_daily_characters`。RPM / 每日请求 0 为不限；模型额度 0 为停用；并发最少 1。统一默认值中 RPM / 每日请求必须大于 0。旧的分项默认设置 API 保留兼容，但网页统一使用 `/admin/quota-defaults`。

批量操作和统一默认设置写入审计，审计不含密码或原始密钥。排查请求时优先使用 request_id，再按用户与时间查记录。实际 IP 明细、生产备份和临时测试材料不进入 Git。

## 发布验证

本次通过 148 项 Python 测试、17 项 Worker/Miniflare 测试，以及浏览器桌面/移动布局和实际操作验证。生产验证使用一次性账号完成真实登录、筛选和详情、可信 IP 与客户端信息、批量封禁/解封、独立额度拒绝，并清理了测试账号及关联数据。既有生产用户的权限与额度未被批量改写。

请求诊断和带审计的额度核对入口已增加，详情见 [可靠性与诊断](gateway-reliability.md)。默认显示待核对预留，管理员应确认提供方实际用量后逐条修正，不应批量退款。

## OpenAI 官方费用

「费用概览」按 UTC 显示本月至今、最近 7 天或 30 天的 OpenAI 组织费用，并按币种分开汇总。当天费用可能延迟入账。组织预付余额可通过同页的「OpenAI 账单与余额」查看。网关预算按北京时间统计，反映网关内部估算和预留。

在 Worker `hilex-accounts` 使用 Secret `OPENAI_ADMIN_KEY`。管理员打开该页时，Worker 按 `OPENAI_TRANSPORT` 配置向 OpenAI Costs API 发起只读请求，生产环境通过受保护的本机中继。浏览器只接收汇总后的日期与分币种金额。查询遇到临时连接或服务故障时最多重试一次，鉴权错误或限流会直接提示。模型调用仍按 `OPENAI_TRANSPORT` 配置走本机中继。

## 全站运行管理

在「全局配置」中展开「云模型预算与注册保护」。Luna 默认每月 $200（北京时间自然月），显示已计入、预留及剩余估算成本；可暂停全部云模型，或单独设置每日语音总量。注册继续开放，支持 IP / 全站每小时与每分钟限频配置。

告警由 Worker Cron 每 15 分钟生成，支持知悉与自动恢复；目前在本后台及 Workers Logs 查看，不发送外部通知。额度核对中 Luna 可同时核对美元成本，CAS 检查旧值并写审计，不因删除账号释放全站已计成本。

地区/入口/模型的成功率筛选、手动合成参考探测、脱敏诊断包下载见 [网络诊断](network-diagnostics.md)；外部 Webhook 的配置状态、测试和投递状态见 [告警投递](alert-delivery.md)。接收端未配置时，测试按钮禁用。

## 用户通告

在 [通知](https://accounts.hilex.me/#notices) 中展开“发布与管理用户通告”，可保存/编辑草稿、选择全体或指定账号、设置生效和过期时间，再发布或撤回。发布后的内容固定，修改需撤回后新建。普通账号仅能看到属于自己的有效通告，不可访问管理接口；与告警中心的运维消息分开。接口与客户端交接见 [用户通告](customer-notices.md)。

公开注册的邮箱验证通过 Worker SMTP 和 D1 实现，历史未验证账号登录后会收到可稍后处理的绑定提醒；管理员创建账号不走公开注册邮件，后续登录可自行补绑定。发信配置、授权码轮换、错误分类及客户端迁移见 [邮箱验证](email-verification.md)。

## 邮箱身份结构

显示名允许重复，后台以固定 ID 和唯一登录邮箱区分账号。创建用户填写显示名与邮箱；无邮箱账号可通过“设置登录邮箱”补全，设置不会代替账号本人验证邮箱。所有额度、密钥、通知、请求和审计继续通过 ID 关联。接口字段详见 [邮箱身份迁移](client-migration-email-identity.md)。
